# 📚 Library Management System (LMS)

A user-friendly Library Management System website designed to present library information, showcase book collections, and provide separate dashboard interfaces for users and administrators. This static website features six pages with a clean layout and organized navigation for an engaging browsing experience.

## ✨ Features

- 🏠 **Home Page** – Introduces the library and highlights its key features.
- 📖 **About Page** – Provides information about the library and its purpose.
- 📬 **Contact Page** – Displays contact information for visitors.
- 📚 **Book Collection** – Showcases books from different categories for easy browsing.Displays a collection of books with titles, authors, categories, and book cover images.
- 👤 **User Dashboard** – Presents a dashboard interface for users to explore their library-related information.
- 🛡️ **Admin Dashboard** – Displays an administrative interface for managing library-related information.
- 🧭 **Easy Navigation** – Allows visitors to navigate smoothly between all six pages.
- 🎨 **Attractive UI** – Features a clean, organized layout with visually appealing design elements.
- 📱 **Structured Layout** – Organizes library information and dashboard sections in a user-friendly format.

## 🛠️ Tech Stack
- HTML5
- CSS3
- Bootstrap 5

## 📌 Project Type
**Static Multi-Page Website**
This project focuses on the frontend interface. The dashboards and other pages are static, with no backend integration or database connectivity.
